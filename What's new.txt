FastViewer - what's new
=======================

Version numbers: major.minor.patch. New features raise the middle number, bug fixes the last one.
You can see which version you have in "..." -> Settings -> About.


1.15.6  (2 Nov 2026)
  Improved (a look at every screen, look and window size)
  - Keyboard and screen readers: Settings can now be used with the keyboard alone (Tab, Space or Enter,
    arrow keys in menus, Esc to go back), with a clear focus ring. Every button has a name that screen
    readers read out. In a shortcut box, Delete removes the key and Tab moves on.
  - Tooltips and menus always show the keys you set: after changing a shortcut they used to show the old one.
  - Small windows: the time bar stays (the skip and repeat buttons make room instead), the play button in the
    middle gets smaller, the Delete message fits, the Info button no longer sits on the zoom box, and the
    Settings side menu scrolls so every page can be reached.
  - Clean look: the File info pane is no longer covered by the floating bars.
  - Files that can't be opened get a plain explanation ("This file is empty", "This video is incomplete,
    for example a download that didn't finish"...) and an "Open with another app" button. A video that
    failed while you switched very fast gets another try when you go back to it.
  - An empty window no longer shows the last file's details, arrows and file buttons.
  - Easier to read: darker hint text in the light looks and stronger backgrounds behind the side arrows,
    so they show on bright photos too.
  - While Settings is open, the file buttons (Delete, Copy, Rotate, Open with) are off, as in the grid.
  - Slideshow: the button turns into "Stop slideshow", a short message says how to stop it, and full screen
    shows only the Close button in the corner.
  - The first time FastViewer stays ready in the background after you close it, a notice by the clock
    says so (and how to quit). Preload changes right away instead of after a restart.
  - Trim shows long clips as "(20:00 long)" instead of seconds. File info dates are in English.
  - Settings > Keyboard has an icon for every action. A shortened file name in the title bar shows in full
    when you point at it.
  - A grey Windows accent colour made buttons and switches look switched off: FastViewer uses blue then.
  Fixed
  - Changing Preload in one FastViewer window could make another open window crash on its next switch.
1.15.5  (2 Nov 2026)
  Fixed
  - "Couldn't check for updates: The remote server returned an error: (403) Forbidden." GitHub answers
    only 60 update questions an hour per internet connection. When it says no, FastViewer now asks
    GitHub's normal releases page instead (which has no such limit), and if that fails too it says
    "GitHub is busy right now. FastViewer will try again later." and quietly tries again later.
    Updates still only ever download from FastViewer's own GitHub releases.
  - In full screen, Settings' Back button and title sat under the top bar's buttons. The top bar now
    stays above Settings, like in the window.
1.15.4  (2 Nov 2026)
  Fixed (found in a big stress test: thousands of fast switches, odd files, broken settings)
  - A video you skipped past just as it was starting (next, then quickly back) kept playing out of
    sight, with sound, and was already over when you went to it.
  - The Delete message named one file, but if the mouse wheel, a mouse side button or the slideshow
    moved on while it was open, OK deleted the file shown by then. Now it always deletes the file it
    names, and nothing moves on while it's open.
  - A damaged or hand-edited settings.ini could stop FastViewer from starting at all, or quietly reset
    every setting after one unreadable line. Unreadable lines are now skipped (and noted in
    %TEMP%\FastViewer\crash.txt) and odd values are kept within range.
  - Leaving Settings while a shortcut box said "Press a key..." made the next key you pressed
    anywhere become that shortcut.
  - With "Also save it to the file" on, a photo you rotated and then quickly left wasn't saved.
  - Updating with a second FastViewer window open (or one waiting in the background) failed with
    "Windows doesn't allow changing files". Updating now works, and the FastViewer waiting in the
    background makes way for the new version.
  - Folders with thousands of files sorted by date (or with shuffle on) froze FastViewer for seconds,
    also each time a file was added. Now well under half a second.
  - Animated GIFs used far too much memory (over 2 GB for a folder of HD GIFs): only the GIF on
    screen keeps its frames now.
  - Closing the window while "Saving clip" or "Make compatible copy" was still busy left a broken,
    half-written video. The window now disappears and FastViewer closes once the video is saved.
  - Where you left off in videos: several FastViewer windows wiped out each other's places, and the
    list of 300 forgot videos you had just watched again.
1.15.3  (2 Nov 2026)
  Fixed
  - The mouse wheel over the speaker button changes the volume again (it stopped in 1.15.0, when
    pointing at the speaker started opening the volume slider).

1.15.2  (2 Nov 2026)
  Fixed
  - In the Clean look and in full screen, the message at the top ("Update now", "Start over",
    the trim bar) sat under the top bar and couldn't be clicked. It now appears just below it.

1.15.1  (2 Nov 2026)
  Fixed
  - With more than one FastViewer window open (or one waiting in the background), a setting changed
    in one window didn't reach the others: they kept the old one (for example the video still
    dimmed with "Dim video" off) and could even put it back when they closed. Now every window
    picks up changes made in another as soon as you switch to it.
  - If FastViewer ever can't save its settings, the reason goes to %TEMP%\FastViewer\crash.txt.

1.15.0  (1 Nov 2026)
  Changed
  - Volume: point at the speaker button and the volume slider opens by itself; it closes a moment
    after you move away. Clicking the speaker now mutes and unmutes (like YouTube). On a touch
    screen a tap opens the slider.

1.14.0  (1 Nov 2026)
  New
  - Looks: Settings > Appearance (now at the top) has four, each with a small preview, and it
    switches right away:
      Photos        like the Windows 11 Photos app (how FastViewer always looked)
      Clean         just the picture; quiet controls float over it and fade in when you move the mouse
      Liquid Glass  Apple-style frosted glass over your blurred desktop, spring motion, line icons
      Midnight      pure black (or pure white), no boxes, thin text
    Each can be dark, light, or follow Windows.
  - Choose your buttons: Settings > Buttons switches any button on or off, with the presets
    All buttons, Essentials and Minimal. Hidden buttons still work with their keyboard shortcut
    and from the "..." menus, under "Hidden buttons". Arrows on the sides and the play button in
    the middle moved here too. Picking Clean suggests the Minimal buttons (you don't have to).
  - Reset to default for both.
  Other
  - If FastViewer ever crashes, the reason is saved in %TEMP%\FastViewer\crash.txt.
  - Liquid Glass and Midnight use the Inter font (included; SF Pro if you have it installed).

1.13.0  (1 Nov 2026)
  Better
  - Uses much less memory with big photos: they're kept at screen size (a 12 MP photo takes
    about 10 MB instead of 48 MB), and the full photo loads by itself when you zoom in further.
    Going through a folder of 12 MP photos now peaks around 250 MB instead of 1.3 GB.
  - Pictures FastViewer no longer needs are given back to Windows right away, once you pause.
  - Photos open a little faster too (less to decode).
  Fixed
  - On slower PCs FastViewer could freeze for several seconds at heavy parts of a video (Windows
    then turns the window pale). It no longer waits for Windows' video player when the PC is busy.

1.12.0  (1 Nov 2026)
  New
  - Play button in the middle: Show, Only when paused (like YouTube) or Hide.
    Settings > Videos. Clicking the video still pauses and plays.
  - Hide controls on a paused video too (Settings > Videos, off by default): the controls and
    dimming fade while paused as well, so you can look at a clean paused frame.
  - Volume, mute and skipping with a key or the wheel show a short note ('Volume 45%',
    '+30 s  1:42 / 5:00') when the controls that would show it are hidden.
  - The mouse pointer hides over a video when the controls fade, also in a normal window.
  - Arrows on the sides can be turned off (Settings > Viewing).
  - Grid: a Names button shows the file names under the thumbnails.

1.11.0  (1 Nov 2026)
  New
  - Change the keys for everything: Settings > Keyboard now lists every action, including
    Copy file path, Show in folder, Open with, Keep on top, Save a frame, Make compatible copy,
    Save rotation to file, Actual size, Thumbnail strip on/off, Close window, and Slower / Faster /
    Normal speed for videos. The new ones have no key until you give them one.
  - Two keys per action: click a box and press a key, right-click a box to remove that key.
  - Settings > Mouse: choose what the side buttons, the middle button and double-click do, and
    whether a click on a video pauses it. The mouse wheel setting moved here too.
  - Esc always goes back (full screen, mini player, grid, Settings), so you can't get stuck.
  Fixed
  - Settings now shows the current state of options you changed from a menu or key (Keep on top).

1.10.0  (1 Nov 2026)
  New
  - All files in the folder: G (or the new grid button in the bottom bar) shows every photo and
    video as thumbnails, in File Explorer's order and with your Show filter. Click one to open it,
    or use the arrows and Enter. Small / Medium / Large, or Ctrl + mouse wheel. Esc goes back.
    While shuffle is on the grid stays in folder order; picking a file keeps shuffling from there.
  - Thumbnail strip (Settings > Viewing, off unless you turn it on): small pictures of the files
    before and after this one, under the picture. Click one to jump to it. With shuffle on it
    shows the shuffled order, so you see what comes next.
  - Thumbnails are the ones File Explorer uses and load after you stop switching: switching
    stays exactly as fast as before (measured).
  Changed
  - A file you open from File Explorer while FastViewer is open now gets a window of its own
    instead of replacing what you're looking at. FastViewer waiting in the background still opens
    the first file instantly; when you close windows, one stays ready and the others quit.

1.9.0  (1 Nov 2026)
  New
  - Opens instantly: after you close FastViewer it stays ready in the background (icon next to
    the clock, right-click > Quit), so the next file opens in a blink. Settings > Speed.
  - One window: double-clicking another file shows it in the open FastViewer.
  - New files in the folder (a finished download, a clip you saved) appear by themselves.
  - Keyboard shortcuts can be changed: Settings > Keyboard.
  - Shuffle (X, or "..." > Shuffle).
  - "When a video ends": stop, or play the next file (Settings > Videos). Repeat works as before.
  - Click the video to pause or play; double-click still goes full screen.
  - Mouse wheel over the volume button changes the volume, over the time bar it jumps;
    over the other video buttons it no longer switches files by accident.
  - Full screen: the top and bottom bars appear when you move the mouse.
  - Settings has a side menu (Viewing, Videos, Keyboard, Speed, ...), and Back stays visible.
  - The "..." menu is grouped into File and View.
1.8.0  (1 Nov 2026)
  New
  - Automatic updates: when FastViewer starts (at most once a day) it checks
    github.com/real4tk/FastViewer for a newer version and offers "Update now".
    Nothing is installed without your click, and your settings stay.
    Settings -> Updates has an on/off switch and "Check now".

1.7.0  (1 Nov 2026)
  New
  - Continue where you left off: videos longer than a minute start again where you stopped
    ("Start over" button in the message that appears). Can be switched off in Settings.
  - Frame by frame: , and . step one frame back or forward (also in the video "..." menu).
  - A-B loop: [ sets the start, ] the end, \ stops it. The looped part shows on the time bar.
  - Trim (Ctrl+T or video "..." -> Trim): pick a start and end, save that part as a new .mp4.
  - Make compatible copy (video "..." menu): saves an .mp4 that plays and gets thumbnails
    everywhere, upright and in normal colours. Uses Windows' own video tools, no extra programs.
  - Animated GIFs play.
  - Photos: "When you rotate a photo" setting can save the rotation into the file
    (JPEGs without any quality loss), plus "..." -> "Save rotation to file".
  - Faster: "Preload" setting, now 2 files each way by default, so even very fast clicking
    through videos stays instant. FastViewer also starts a little quicker, and Settings has an
    optional "Start even faster" button (needs administrator approval once).

1.6.1  (30 Oct 2026)
  Fixed
  - Videos filmed upright on a phone (for example iPhone HDR videos) opened sideways.
    FastViewer now reads the rotation stored in the video and shows it the right way up.
  - "Save a frame" now saves the frame the way it's shown, also for turned videos.

1.6.0  (26 Oct 2026)
  New
  - Mini player (Ctrl+M or the button left of "Open with"): just the video in a small
    window that stays on top of other apps. It takes the shape of the video and changes
    shape when you go to the next file or rotate. Drag to move, drag the edges to resize,
    double-click or Esc to go back.
  - "Keep on top" option ("..." menu and Settings) for the normal window.
  - The window can be made much smaller; buttons tuck into the "..." menu when there's no room.

1.5.0  (25 Oct 2026)
  New
  - Rotate photos and videos 90 degrees (button at the top, Ctrl+R, or "..." -> Rotate).

1.4.2  (19 Oct 2026)
  Fixed
  - No more FastViewer logo stamped on video thumbnails in File Explorer.

1.4.1  (19 Oct 2026)
  Fixed
  - Controls now fade away as soon as the mouse leaves the window, instead of after 2.5 seconds.

1.4.0  (19 Oct 2026)
  New
  - Choose how far the skip buttons (and J / L) jump: 5, 10, 15, 30 or 60 seconds.

1.3.0  (19 Oct 2026)
  New
  - Play/pause button in the middle of videos, styled like the Windows Photos app.
  - Video dims slightly while the controls are showing, like Photos.
  - Settings page: mouse wheel, zoom preference, which files to show, order, wrap around,
    ask before deleting, autoplay, repeat, dimming, hide delay, slideshow speed.
  - Save as (Ctrl+S) and "Save a frame" from a video.
  Fixed
  - Top bar no longer overlaps itself in narrow windows.
  - No black flash when resuming a paused video.

1.2.0  (19 Oct 2026)
  New
  - Center play/pause button; controls stay visible while paused.
  Fixed
  - No black flash between videos when switching quickly.

1.1.0  (19 Oct 2026)
  New
  - Windows 11 Photos look: top bar, bottom bar, file info, zoom, slideshow, delete to Recycle Bin.
  - Files go in the same order as File Explorer (for example newest first in Downloads).
  - New black-and-white icon.

1.0.0  (19 Oct 2026)
  - First version: instant switching between photos and videos (the next and previous
    files are loaded ahead of time).
